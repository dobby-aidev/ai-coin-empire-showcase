## 🚀 Overview

**AI COIN EMPIRE** is an advanced real-time financial and cyber strategy simulation. Players construct global crypto-mining empires, deploy autonomous AI agent cores (Dona Codex), issue corporate tokens via Initial Coin Offerings (ICO), wage tactical zero-day cyber warfare, and manage mega-datacenter networks across worldwide metro regions.

---

## 🎮 Core Simulation Modules

### 1. ⚡ AI GPU & Quantum Mining Grid
- **Hardware Architecture**: Scale from baseline ASIC arrays and GPU rigs to sub-zero liquid-cooled quantum compute matrices.
- **Dynamic Tuning**: Overclock clock frequencies, regulate power draw, and balance thermal dissipation for maximum hashrate yield.

### 2. 📈 Dynamic Exchange & Proprietary Token Issuance (ICO)
- **Tokenomics Engine**: Launch custom company tokens with configured supply, liquidity reserves, and initial pricing.
- **Order Book & Volatility**: Trade top crypto assets (BTC, ETH, SOL, DONA) with live candlestick analytics, high-leverage order books, and algorithmic price fluctuations.

### 3. 🛡️ Tactical Cyber Warfare & Zero-Day Ops
- **Offensive Operations**: Execute targeted DDoS strikes, botnet infiltrations, and brute-force hash-cracking against rival corporations.
- **Hardened Defense**: Upgrade multi-layered AI firewalls, intrusion detection honeypots, and self-healing security protocols.

### 4. 🌍 Global Data Centers & Regional Grid
- **Strategic Hubs**: Deploy and lease server infrastructure across major tech corridors (Frankfurt, Tokyo, Silicon Valley, Singapore, London, São Paulo).
- **Latency & Redundancy**: Optimize low-latency backbone cables, redundant power feeds, and global bandwidth capacity.

### 5. 🧠 Dona Codex: 3-Phase Autonomous AI Evolution
- **Phase I (Core Neural Mesh)**: Predictive market sentiment evaluation and automated trading micro-bots.
- **Phase II (Self-Healing Grid)**: Autonomous incident triage, dynamic load reallocation, and cyber threat neutralization.
- **Phase III (Omni-Link Singularity)**: Global simulation hegemony with quantum algorithmic optimization across all financial and computing operations.

### 6. 🏆 Multiplayer Alliances & Global Leaderboards
- **Corporate Alliances**: Form syndicates, pool computing hashpower, and coordinate joint cyber incursions.
- **Live Leaderboard**: Real-time net-worth valuation, hashrate index, and tactical dominance rankings.

- **Frontend & UI**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Canvas Simulation.

## 💻 Local Development Setup

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm** or **pnpm** / **yarn**

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/dobby-aidev/ai-coin-empire-showcase.git
cd ai-coin-empire-showcase
npm install
```

### 2. Configure Environment Variables
Create a `.env` file in the root directory:
```env
# Optional Firebase Configuration (if using cloud persistence)
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or the port specified in terminal) to launch the simulation.

### 4. Production Build
```bash
npm run build
```
